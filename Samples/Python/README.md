# README

## Requirements

This project was tested using Python `3.11.9`. Using a different Python version (e.g. `3.13`) will cause `pip install -r requirements.txt` to fail.

## Setup

To run the Jupyter Notebook scripts, create a new virtual environment using Python `3.11.9` specifically. If you have multiple Python versions installed, use the [`py` launcher](https://docs.python.org/3/using/windows.html#launcher) to select it explicitly:

```bash
py -3.11 -m venv .venv
```

Then install the required dependencies:

```bash
.venv\Scripts\pip install -r requirements.txt
```
